# Git Commands Practice

| Command | Purpose |
|---|---|
| `git init` | Initializes a repository |
| `git status` | Checks the status of files |
| `git add .` | Stages changes |
| `git commit -m "message"` | Saves a snapshot of staged changes |
| `git log --oneline` | Displays commit history |
| `git branch` | Lists branches |
| `git switch -c branch-name` | Creates and switches to a branch |
| `git merge branch-name` | Merges a branch |
| `git remote -v` | Displays remote repositories |
| `git push` | Uploads committed changes |
| `git pull` | Fetches and integrates remote changes |
| `git diff` | Displays unstaged changes |
